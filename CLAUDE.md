# Repository instructions

Read and follow [AGENTS.md](AGENTS.md), including the decisions log and development
workflow it references. For user-facing changes, add a uniquely named note in
`changelog.d/` as described in [its README](changelog.d/README.md); do not edit
`CHANGELOG.md` for new entries. Run `python scripts/render_changelog.py` to view
the notes with the existing history.
