Flow: `reply_to_ticket` (`admin_case_bp.py:619`) → `queue_admin_reply` (`process_support_tickets.py:496`) → `EmailSender.queue_email()` which inserts into `email_queue` tagged with that process's `instance_id`. The only thing that ever sends queued jobs is each `EmailSender` instance's in-process thread doing `find_one_and_delete({"instance_id": self._instance_id})` (`EmailSender.py:51-60`) — i.e. only the exact process that queued the job can ever send it. If that worker restarts (deploy, gunicorn `max_requests`, `ENABLE_EMAIL_WORKER=false`, or the job is queued from a short-lived job-runner process like `poll_once` at `process_support_tickets.py:571`), the job is orphaned forever. There is no global drainer on this branch. Meanwhile the admin gets a green flash "Vastaus lähetetty sähköpostitse." (`admin_case_bp.py:668`) regardless of whether it was ever actually delivered — a false confirmation.
