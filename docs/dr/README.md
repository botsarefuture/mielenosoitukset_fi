# Recovery tooling

This directory contains public development documentation only.
Operational recovery procedures, deployment profiles, topology, schedules, cost
limits, authorization records and rehearsal evidence are maintained privately
with restricted access. Do not add them to this repository or pull requests.

Publishing generic tooling does not authorize provisioning, capacity expansion,
production changes or traffic cutover. An operator must obtain and privately
record explicit owner authorization for any resource expansion before execution.
No cloud provisioning or automatic spending capability is provided by the current
local recovery controller.
