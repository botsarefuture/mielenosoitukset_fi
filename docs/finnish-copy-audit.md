# Finnish wording audit

Source snapshot: `050b3ed1` (origin/main), 14 November 2026.
Model used for the language review: `gpt-6.1-sol`. This is a source-based
language audit, not a Finnish model benchmark or a production browser acceptance.

Scope: public and regular-user UI, including account pages, accessible labels,
form help, errors and notifications. Admin screens, admin-only branches and
admin messages are excluded. User emails are the next phase, after the UI
checklist is complete. English and Swedish remain for human translators.

This PR applies wording corrections in the public React UI, regular-user
Flask pages and retained public templates. Layout, styles, routes, account
behavior and email content are unchanged. Count-dependent wording is corrected
for one participant and one demonstration. Generated frontend assets are rebuilt.
The [inventory](finnish-copy-inventory.md) distinguishes reviewed sources,
implementation and remaining runtime checks. Source links below point to the
audited pre-change snapshot so the original excerpts stay verifiable.

## How to use the proposals

- Fix clear spelling, grammar and agreement errors first.
- Treat naturalness, terminology and shorter wording as editorial proposals,
  not proof that the original is ungrammatical.
- Check the whole rendered sentence, singular/plural cases and substituted
  values before applying a correction. Several findings need a conditional
  text form; a blind search-and-replace would be wrong.
- Prefer current React catalogs over legacy Flask copies. Keep existing
  bridge/parity contracts and generated fallbacks consistent when applying
  changes. Do not hand-edit generated assets or generated campaign fallbacks.
- Preserve policies, dates, consent and retention promises. This review does
  not approve changes to their meaning or establish their legal accuracy.
